What any freelancer return needs

Schedule C (profit or loss), Schedule SE (self-employment tax), Form 8995 for the 20% QBI deduction, and Schedule 1 for the deductible half of SE tax, self-employed health insurance and retirement contributions. Add Form 8829 if you use the regular home office method. All the software above handles these.

When to pay a professional instead

An S corp return (Form 1120-S), a big one-off event (selling a property or a business), several states, or an IRS letter you don't understand. Software is fine for a normal Schedule C year.

Questions

Can I file a Schedule C for free?

FreeTaxUSA files the federal return with Schedule C at no charge; the state return costs a small fee. Most big-name software charges for self-employment.

Does tax software do quarterly estimated taxes?

Most will print 1040-ES vouchers for next year after you file. To work out a payment during the year, use our free calculator or a tracker.

Is Keeper worth it?

If you never tracked expenses, finding even a few missed write-offs can cover it: each $1,000 of deductions saves about $230 in federal tax at $60,000 of profit. If your books are already tidy, cheaper filing software does the same job.
