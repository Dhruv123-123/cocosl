alert_date: 2026-11-18
severity: warning
scam: Marketplace "buyers" who ask for a code to prove you're real
channel: marketplace chat
sender: a buyer for something you listed
subject: Scam alert: "send me the code to prove you're real"
preheader: A code someone sends you is a key to your account. Never read it back.
example: Hi, is the stroller still available? Before I drive over, I want to make sure you're real. I'm sending you a code, just tell me what it says.
flags: make sure you're real | I'm sending you a code | tell me what it says
tell_1: The buyer wants to "verify" you before they've even seen the item.
tell_2: A code arrives by text that you never asked for.
tell_3: They push you to read it back. That code lets them set up an account in your name or get into yours.
do_1: Never share a code someone sends you, with anyone.
do_2: Keep the chat inside the marketplace app, and sell in person, in a public place.
do_3: Report the buyer in the app, then block them.
if_already: Read out a code? Change the password on your email and phone accounts now, turn on two-step sign-in, and ask your carrier to add a PIN.
source_title: FTC: Selling stuff online? Here's how to avoid a scam
source_url: https://consumer.ftc.gov/consumer-alerts/2022/07/selling-stuff-online-heres-how-avoid-scam
explainer: verification-code-scams
