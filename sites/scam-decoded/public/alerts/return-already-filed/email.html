"A return was already filed with your SSN"

Arrives by: e-file rejection or IRS letter · From: the IRS (this one can be real) (fictional example)

Your e-filed return was rejected: a return using this Social Security number has already been filed for tax year 2026.

3 tells

  1. Your e-file is rejected because your SSN was already used.
  2. An IRS letter about a return you didn't file.
  3. Texts that "help" you fix it are scams.

Do this

  1. Follow the IRS identity theft guide on irs.gov.
  2. Get an IP PIN at irs.gov to lock future returns.
  3. Report it at IdentityTheft.gov.
