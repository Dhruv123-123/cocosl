# Your First $1,000 Invested: compliance review

A human reviewer ticks every line below for each part before it's uploaded. This is an education series, not advice, and it should read that way throughout. The repo's guardrails already block hype words, promises and testimonials; this list covers what they can't check.

## Every video

- [ ] **No specific securities.** No fund names, tickers, providers or brokerage screens. Any screen recording added later uses a generic mock-up.
- [ ] **Hypothetical returns are labelled** in the narration, on the chart (its note) and in the caption or description. No return is described as expected or likely.
- [ ] **Risk disclosure** is in the description, and the narration mentions that values can fall.
- [ ] **Fees are mentioned** wherever costs or returns are compared.
- [ ] **Tax figures and rules** are checked against IRS.gov in the month of posting. The series avoids quoting yearly limits on screen; if any are added, verify them.
- [ ] **Fair and balanced.** Each choice shows its trade-offs (lump sum vs monthly, index vs target-date vs robo, Roth vs traditional). Nothing says one option is right for the viewer.
- [ ] **Affiliate disclosure** is in the description of any part that links a /compare/ page, and that page itself is checked to be fair and balanced.
- [ ] **Not personalised advice.** The education line is in the description. Fictional examples are clearly fictional.
- [ ] **Sources** in the description resolve and support the claims listed under `claims_to_verify`.

## Per-video flags

### Part 1: Before You Invest Your First $1,000: The 4-Box Checklist

- [ ] Hypothetical 7% return: labelled illustrative on screen and in the description
- [ ] 'Paying off 24% is like earning 24%': framed as an equivalence, no investment return promised
- [ ] ~8% debt threshold presented as a rule of thumb, not advice
- [ ] Employer match formula is an example; viewers told to check their own plan
- [ ] Verify the numbers: $1,000 × 24% = $240 interest a year; $1,000 × 7% = $70 (hypothetical); 50% match up to 6% is a common example formula; ~8% debt threshold is a rule of thumb

### Part 2: Where to Put Your First $1,000: 401(k), IRA or Brokerage?

- [ ] Tax rules (Roth withdrawals, early-withdrawal penalty, IRA deductibility) are summaries: verify against current IRS guidance
- [ ] No specific limits quoted on screen: viewers sent to IRS.gov for current figures

- [ ] Vesting caveat included with the match
- [ ] Verify the numbers: $1,000 + 50% match = $1,500; Roth contributions (not earnings) generally withdrawable tax- and penalty-free; Early 401(k) withdrawals before 59½ generally taxed + 10% penalty, with exceptions; IRA limits and Roth income limits change yearly
