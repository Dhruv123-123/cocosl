# YouTube plan: Tiny Histories

Made by `factory youtube-plan` from launch/tiny-histories/content.json. These are set by hand in YouTube Studio: the API has no
end-screen or related-video endpoint. About 5 minutes per long video.

## End screen layout (make it once, then "Import from video" on each upload)

- Left: the next video in this series (specific video)
- Right: Best for viewer
- Subscribe button

Every long video ends on a 20-second slate with space for these elements, so they never cover the
explanation.
