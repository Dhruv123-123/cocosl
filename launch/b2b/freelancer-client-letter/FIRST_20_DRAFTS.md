**Before each send (3 minutes):**

1. Open the firm's own website (or find it). Directory profiles go stale, and some, like the Lantern pages, are
   machine-written. If the website contradicts the personal line, rewrite the line from the website.
2. Find the contact address the firm publishes for enquiries. Never guess one. Put it in `contact_route` in
   `PROSPECTS.csv`. No published email? Use their contact form, or skip and move the next firm up.
3. Find the owner's first name on their site if you can. Otherwise use "Hello".
4. Check they don't already send a client newsletter. If they do, skip them.
5. Fill `{Your name}` and `{Your mailing address}`, and log the send in `../PIPELINE.csv`.
