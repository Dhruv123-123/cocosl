# Freelancer Money Bundle: member code and group license (draft)

**Draft for Dhruv. The prices and terms are proposals, not settled.** Change them before you quote
them, and check with someone who knows contract law before you sign anything bigger than the
$499 tier. The normal store listing says "for personal use; please don't resell or redistribute", so a
group license is the only way a group may hand out copies.

## The three options

| Option | Price (proposed) | What the group gets | How you deliver it |
|---|---|---|---|
| Member code | $39 per member ($10 off $49) | A code to share with members; each member buys their own copy | Store discount code `MEMBERS-{GROUP}` |
| Group license, small | $199 one-time | Up to 25 members get the bundle free, as a member perk | Private download link + license note |
| Group license, standard | $499 one-time | Up to 100 members | Same |
| Bigger groups | Quote it | Over 100 members (e.g. EFA, Freelancers Union, NWU) | Talk first; consider $4–5 per member, with a cap |

Why these numbers: $199 for 25 people is about $8 each and $499 for 100 is about $5 each, against $49
retail. That's a real discount for the group, and still worth it for a one-time setup email. The member
code costs you nothing to run, so offer it first to anyone who hesitates.

## License summary (paste this into the reply)

```
Group license: Freelancer Money Bundle (1099 Money)

- Licensee: {Group name}
- Seats: up to {25 / 100} current members, staff or volunteers of {Group name}.
- You may share the private download link with those members through your own channels (newsletter,
  member portal, Slack). Please don't post it publicly or share it outside the group.
- Each member may use the files for their own freelance business. Members may not resell or
  redistribute the files.
- Price: {$199 / $499}, one-time. Covers the 2027 edition and any free fixes to it during 2027.
- The bundle is educational material, not tax, legal or financial advice.
- Refunds: within 14 days if you haven't shared the link yet.
```

## Setup checklist (do once, before the first "yes" to a perk)

1. Create the discount code template in the store (Gumroad: Offer codes; Lemon Squeezy: Discounts).
2. Create one private product per tier ("Freelancer Money Bundle: group license, 25 seats") with the
   same zip, plus a `LICENSE.txt` containing the summary above.
3. Make a payment link for each tier.
4. Add a row to `TRACKER.csv` (`offer` = code / license-25 / license-100) when a group says yes.
