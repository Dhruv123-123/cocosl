# Scam Red Flags: Posters and Wallet Cards (Etsy + Gumroad listing kit)

**Printables only, so it can go on Etsy.** Etsy's 22 Oct 2026 rule bans AI-generated *functional guides*
(instructions buyers rely on). This product is wall signage and pocket cards: short red-flag lines, no steps and no
how-to pages, the same reading `launch/catalog/etsy_rules.py` (PR #6) uses to keep the Scam Decoded Card Set on Etsy.
The name avoids "guide" and "kit" on purpose. Don't add pages of advice to it, or it moves to Gumroad only.

Suggested price **$7** (the Card Set is $6, the Seniors pack $7). That's a suggestion; the price is Dhruv's call.
Don't publish until Dhruv has opened every PDF, printed one poster and one card sheet, and checked each line
against the sources page.

Build: `python3 build.py` (Chromium + pdftoppm). Files land in `dist/`, which is gitignored, so rebuild before
uploading. A copy sits in project files under `content-factory/scam-decoded/red-flags-printables/`.
